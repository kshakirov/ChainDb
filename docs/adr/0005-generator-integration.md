# ADR 0005: Интеграция живых курсоров в квантованные циклы

## Status
Proposed (Бэклог / В планах)

## Context
Тяжёлые команды ядра не должны аллоцировать в памяти гигантские списки данных (например, миллионы ключей при `KEYS *`), чтобы не вызывать Cache Misses и перегрузку Garbage Collector. Данные из хэш-таблиц должны считываться лениво и поштучно.

## Proposed Decision
Интегрировать изолированные фабрики курсоров `make-generator` (Шаги 2 и 3) как поставщиков данных внутрь квантованных циклов команд (Шаг 4). 

Логика сквозной цепочки:
1. Цикл команды на каждой итерации дёргает внутренний генератор `(next-key)`.
2. Генератор делает один шаг по физической памяти базы, отдаёт ключ в цикл и засыпает.
3. Цикл пакует ключ в сетевой буфер. При достижении лимита итераций (например, каждые 5000 ключей) цикл вызывает системный `async-yield`.
4. Диспетчер замораживает всю матрёшку вычислений целиком, отправляя её в хвост планировщика.
